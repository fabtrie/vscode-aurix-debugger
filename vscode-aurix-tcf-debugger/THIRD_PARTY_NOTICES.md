# Third-Party Notices

The MIT license in [`LICENSE`](LICENSE) covers the source code of this
repository: the extension (`src/`, `scripts/`, `media/` and the project
configuration files) and the `aurix-dbg` debug server under
[`aurix-debugger/`](https://github.com/fabtrie/vscode-aurix-debugger/tree/main/aurix-debugger),
from which `bin/aurix-dbg.exe` is built. The exceptions are listed below.

## Files shipped under `bin/` that are not covered by the MIT license

### SVD files

The SVD files under `bin/svd/` (except `HSM_TC3xx.svd.gz`, which is generated by
`scripts/gen-hsm-svd.js`) are owned by Infineon Technologies AG and
redistributed under their own license.

### OpenOCD Tcl scripts

`bin/openocd/tcl/` contains the configuration scripts (board, target, interface
and helper files) of OpenOCD, taken unmodified from the TriCore fork at
https://github.com/tricore-oss/openocd. They are licensed under the GNU General
Public License, version 2 or later, unless a file states otherwise in its SPDX
header. The license texts are included in `bin/openocd/COPYING` and
`bin/openocd/LICENSES/`; the exact source commit is pinned in
`aurix-debugger/server/crates/openocd-tcl/build.rs`.

## Third-party code in `aurix-dbg.exe`

`aurix-dbg.exe` is linked statically and contains the following third-party
code, each under its own license:

| Component | Used for | License |
|---|---|---|
| [Jim Tcl](https://github.com/msteveb/jimtcl) 0.83 | Tcl interpreter for the OpenOCD scripts (`crates/jimtcl`) | BSD-2-Clause |

| [TAS Client API](https://github.com/Infineon/tas_client_api) | `crates/tas` is a Rust port of its read/write client | Apache-2.0 |
| Rust crates listed in `aurix-debugger/server/Cargo.lock` | Runtime, HTTP server, DWARF, serialization, ... | Mostly MIT or Apache-2.0 (at the user's choice); also BSD-2-Clause, BSD-3-Clause, ISC, Zlib, Unicode-3.0 and BSL-1.0 options |

The license of each crate is in its `Cargo.toml` (`cargo tree -e normal --format "{p} {l}"`
in `aurix-debugger/server` lists them).

## Not included

- `isystemConnect.dll`, the iSYSTEM winIDEA SDK library used by the `winidea`
  backend, is not part of the repository or the extension. `aurix-dbg` loads it
  at runtime from a winIDEA installation or the SDK (see
  `aurix-debugger/server/crates/winidea-sdk/README.md`).
- Infineon's `tas_server` is not included; it comes with Infineon's tools.
